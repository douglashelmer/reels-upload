Política de Privacidade – Reels Upload

Última atualização: 7 de novembro de 2026.

O Reels Upload é uma ferramenta de uso pessoal de Douglas Helmer, que roda apenas no computador do próprio dono, para enviar e agendar vídeos no seu canal do YouTube.

Dados acessados

Com a autorização do dono da conta Google, o app usa a YouTube Data API para: enviar vídeos, definir título, descrição, miniatura e data de publicação, e consultar informações básicas do canal. Nenhum outro dado é acessado.

Armazenamento

O token de autorização fica salvo apenas localmente, no computador do dono. Nenhum dado é enviado a servidores de terceiros, vendido, compartilhado ou usado para publicidade.

Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
